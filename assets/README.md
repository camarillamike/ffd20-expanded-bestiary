# Creature artwork

The [creatures folder](creatures/) contains the portraits and token images used by the compendiums. Foundry loads them with the actor; you do not need to download or assign them individually.

Different elemental Bomb forms have their own artwork. [Compare the Bombino and Cherry Bomb portraits](../docs/bomb-forms.png), or see the [artwork credits](../docs/credits.md#artwork) for sources and attribution.
