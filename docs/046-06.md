# v0.1.46 group 6

Verifier evidence: the Flan immunity list has its one selected element **and precision**, which is an ooze trait, not another element. The test projects all eight forms independently against their own four printed spell rows. Ice Gigas has Perception +10 in its header but +13 in Skills; the actor uses +13 and notes the conflict. Ironback's default-off jumping modifier raises Acrobatics +11 to +19. Named elementals and the witch now use the printed MP in both the stored pool and prepared class calculation.

Source read independently from all ten original pages. Group test constructs and hydrates 17 actors in memory, checks selected DCs, recharge, damage and form count, with no generated item fallbacks. These are source previews, not reopened packages. The shared ice-spell repair has now been retested.
