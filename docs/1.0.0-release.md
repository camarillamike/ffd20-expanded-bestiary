# FF D20 Expanded Bestiary v1.0.0

This release brings **1,052 actors from 944 Final Fantasy d20 bestiary entries** to Foundry VTT 13. The 15 compendiums include creature variants, bosses, and companions. Use the attacks, spells, equipment, and abilities on each creature's sheet. GMs can also create separate elemental Bomb actors from the original creature's sheet.

**Requires:** Foundry VTT 13, the FFd20 game system, and the FFd20 Content module.

**Install:** In Foundry Setup, open **Add-on Modules > Install Module** and paste this manifest URL:

```text
https://raw.githubusercontent.com/camarillamike/ffd20-expanded-bestiary/main/module.json
```

**Already installed?** Use **Update** in Foundry Setup. Open your FFd20 world, enable the module, and find the creatures under **Compendium Packs > FFD20 Expanded Bestiary**. No console script or bulk import is needed. Updating the compendiums leaves your existing world actors alone.
