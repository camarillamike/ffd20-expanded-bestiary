# GM guide

[Install or update the bestiary](../README.md#install), then open **Compendium Packs > FFD20 Expanded Bestiary** in your FFd20 world.

| At the table | Where to look |
| --- | --- |
| Find a creature | Browse the [compendium directory](../packs/README.md) by creature type, or find its name in the [actor index](../source/actors.json). |
| Make an elemental Bomb | Use [Create Bomb Form](../variants/README.md) on the original actor's sheet. |
| Track a recharge | Use the ability from the placed token's sheet. See [when the charge returns](round-recharge.md). |
| Check an adaptation | Follow the [creature's source record](../source/README.md) to its statblock. |

### Run a creature

For example, open **Expanded Animals**, drag a **Coeurl Kitten** onto the scene, and open its token sheet. In **Combat**, a standard Claw attack rolls once; **Full Attack** on that same Claw entry rolls twice. Bite has its own entry. To keep a version you can customize for later encounters, drag the compendium actor into your world's Actors directory first.
