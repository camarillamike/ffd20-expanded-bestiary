# Artwork in the 0.1.43 expansion

77 of the 100 source entries supply their own page artwork. The pack uses a local copy for both the actor and its prototype token so tabletop use does not depend on hotlinking. Ogre uses the matching Ogre portrait from FFd20 Content (original path: `modules/ffd20-content/assets/bestiary/Ogre-ff1-ps.png`). The remaining 22 use original generated illustrations based on the individual entries, not official illustrations.

## Alternate forms

Base Fire Bomb T1 and Fire Medium Flan retain their published art. Eight Bomb T1 illustrations and seven alternate Medium Flan illustrations were commissioned through image generation using each base silhouette as a visual reference. Each element has a separate transparent bitmap shared by the matching portrait and prototype token. Other modules' art and existing world actors are not rewritten.
