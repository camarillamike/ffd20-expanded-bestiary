# Creature art for v0.1.45

Each embedded actor uses module-local art for both the portrait and the prototype token. A world import does not need to fetch an image from the bestiary site. The creature's canonical page is recorded on each actor.

* Published bestiary illustrations are cached from the corresponding entry when available. Animated GIFs are packaged as static PNGs for token rendering.
* Rattlesnake and Huge Ice Elemental use the matching Rattlesnake and Ice Elemental artwork from the FFd20 Content pack (`rattlesnake.png`, `Ice_Elemental.png`).
* Where source art is missing or unavailable, a creature-specific illustration was generated using the creature's description, role and anatomy. These illustrations are interpretations, not official FFd20 artwork. The new elemental Bomb and Huge Flan variants use their base sprite as a visual reference.
* Two statblocks for the same plant can share its portrait. The Orcish Serjeant's Tamed Nakk uses the Nakk species portrait; it remains a separate actor with its own statistics.
