- Test Malboro's four-breath sequence against multiple recipients with mixed saves, then check ordinary breath charges; place eyes, tentacles and offspring using the supplied pack links. On wyrms verify breath-mode cooldown sharing, Dragon Force's +9 magical healing when applicable, and loss of buffs at expiry. ## Reproduction

Runtime handoff: import `tools/runtime/encounters-051-02.mjs`. Diamond's primary Flash opens its one-round DR gap; the Silence follow-up does not. Deploy Ruby's linked tokens manually and turn off **Tentacles exposed** only when both are destroyed. That transition rolls the regrowth interval and swaps any running Drive without renewing its start time. Adjudicate Auto-Reflect once per round. Ultimate's typed card hits update the matching ER trackers after commit, including fully resisted hits; off-card/untyped HP edits need manual tracker adjustment. For Earthen Ward, target the intended allies before using the feat as an owner (normally GM); only in-range, owned targets receive/reset a pool. Per-recipient full Apply and quick Apply with defenses enabled use the same physical DR calculation. A stale dialog must be reopened before spending capacity. These four mechanics are covered by `node tools/test-encounters-051-02.mjs`; live Foundry timing, permissions and token targeting still need smoke testing.

Run `node tools/build-051.mjs --group=2`, then `node tools/verify-051-group-2.mjs`. The latter tests a deliberately broken behavior per actor and resolves all five linked companion IDs in the shipped .50 packs. These are serialized actor checks, not an interactive Foundry smoke test.
