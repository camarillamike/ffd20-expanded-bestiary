# Round-based recharge

Use the ability from the placed token's sheet. If its chat card rolls a recharge interval, use that roll; you don't need to roll again or start a separate timer.

**Example: Machina Worker's Critical Attack.** In a started encounter, using the attack spends its charge. If the Worker uses it on its turn in round 2 and the card rolls a 3, one charge returns on that turn in round 5. Two unlinked Workers track their charges separately. Outside combat, or if the encounter ends before the charge returns, restore it manually.

**Example: Blood Bat's Screech.** This ability has both a daily limit and a minimum interval. When the interval ends, the Bat may use Screech again **if it still has a daily use left**. The interval doesn't refund a use. Outside combat, this interval follows Foundry's world clock, not real time.

To give a creature of your own a similar ability, see [recharge item configuration](development/recharge-items.md). Otherwise, no macro or setup is needed.
