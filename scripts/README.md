# Bestiary automation

Enable the module in an FFd20 world to load its scripts. No console commands or item macros are needed to use the compendium.

- **Round recharge:** A marked ability rolls its recovery interval when used. See [round-based recharge](../docs/round-recharge.md) for timing or [item configuration](../docs/development/recharge-items.md) to set up your own ability.
- **Bomb forms:** A GM can use **Create Bomb Form** on a supported actor sheet to create a separate world actor. See [elemental forms](../variants/README.md).
- **Damage application:** The module uses the recipient's defenses when applying supported damage from a chat card. For example, a Skeleton's DR reduces physical hits that don't bypass it; Bludgeoning bypasses that DR.
