# Find a creature's source

Start with the [actor index](actors.json). Search for the creature's display name to find its compendium, family, and the filenames of its actor and curation record. Variants and companions have separate entries.

For example, [Malboro Menace (Melee)](actors/malboro-menace-melee.json) is the Foundry actor data; its [curation record](curation/malboro-menace-melee.json) connects it to the published statblock. To use the actor in a game, import it from **Expanded Plants** instead of importing the JSON.
